# Visualizaciones

Visualizaciones construidas sobre los datos del grafo. Cada una vive en su
carpeta con el script que arma sus datos, para que se pueda regenerar y auditar.

| Carpeta | Qué muestra |
| ------- | ----------- |
| [`recorridos/`](recorridos/README.md) | Mapa animado del recorrido de cada víctima: secuestro, centro clandestino, asesinato y hallazgo de restos. Dos versiones: con y sin destino final conocido. |
